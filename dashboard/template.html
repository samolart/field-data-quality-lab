How a flag is made

Each officer is compared with the rest of the team on path length, skip-trigger answers, don't-know rate, straight-lining and survey-vs-coupon discordance. Each metric is adjusted for arm, baseline covariates and location, then tested by shuffling officer labels within location 4,000 times. Benjamini–Hochberg q-values control false discoveries across officers.

Correlated metrics form one family, so one behaviour is never counted twice. A red officer shows two independent families at red level, or three flagged.

The whole rule was also run on pure-noise labels: it flagged an average of officers by chance, versus in the real PAD2 data.

What to remember

  • Survey data are real (openICPSR 186241). Call times and durations are simulated: the surveys carry no paradata.
  • Arm labels t1/t3 are ambiguous in the replication files, so the main contrast pools all SMS arms.
  • Path length is partly driven by respondents' own answers. Flags justify back-checks only.
  • No names, phone numbers or locations appear on this page; the data inside are officer-level aggregates.
